Technical SEO checklist: Core Web Vitals targets are LCP under 2.5s, CLS under 0.1, FID under 100ms. Canonical tags prevent duplicate content penalties. Submit XML sitemap to Search Console and verify robots.txt allows crawling of all high-value pages. Add Schema.org structured data markup for rich snippets. Internal linking passes PageRank to priority pages. Understand 301 vs 302 redirect semantics before any URL migration.
