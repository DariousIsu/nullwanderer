Secrets management: never commit secrets — enforce with a pre-commit hook using detect-secrets. Use HashiCorp Vault dynamic secrets for database credentials that rotate per-request with a 1-hour TTL. Use AWS Secrets Manager with automatic rotation for cloud workloads. Inject secrets at runtime via environment variables, not at build time. Separate secrets by environment: dev, staging, and production. Audit all secrets access logs on a quarterly basis minimum.
