Incident response process: Detect via alert or user report. Declare by opening an incident channel and assigning an incident commander. Investigate by gathering all available signals and forming a hypothesis. Mitigate by taking the fastest path to reducing user impact — root cause is secondary. Communicate via status page update and stakeholder Slack message. Resolve once the root cause fix is deployed. Conduct a postmortem within 48 hours of resolution with all involved parties.
