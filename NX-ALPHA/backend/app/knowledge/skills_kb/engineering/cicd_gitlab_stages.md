GitLab CI stages: the stages list defines execution order — build, test, security, deploy. Use rules to restrict jobs to specific branch, merge_request, or tag conditions. Set artifacts:reports:junit to surface test results directly in the MR UI. Use cache:key:$CI_COMMIT_REF_SLUG for branch-level cache isolation. Track deployments with the environment keyword and a URL. Use include: for org-wide shared pipeline templates. Enforce deployment gates on protected branches.
