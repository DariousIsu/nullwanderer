Helm chart structure: Chart.yaml with name, version, and appVersion; values.yaml for defaults; templates/ directory with deployment, service, and ingress manifests; _helpers.tpl for named template functions. Override values with --set key=value or -f custom-values.yaml. Use Helm hooks (pre-install, post-upgrade) for database migrations. Use helmfile for multi-chart orchestration with environment-specific value files across dev, staging, and production deployments.
