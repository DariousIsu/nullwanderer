Terraform state management: use a remote backend (S3 plus DynamoDB lock) to prevent concurrent apply conflicts — state lock timeout is 5 minutes by default. Never manually edit the state file. Use terraform state mv for resource refactoring. Use terraform import for existing resources. Use separate state files per environment (preferred over workspaces) for strong isolation. Encrypt state at rest in the S3 bucket. Always review the plan carefully after any import before running apply.
