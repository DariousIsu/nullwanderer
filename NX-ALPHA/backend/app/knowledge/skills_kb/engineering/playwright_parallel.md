Playwright parallel execution: set workers count in playwright.config.ts (defaults to CPU count). Enable fullyParallel: true for file-level parallelism. Use test.describe.configure({mode: 'parallel'}) for suite-level parallelism. Avoid shared state: use separate browser contexts per test, generate unique test data with faker, and isolate database state via unique schema per worker. In CI, shard test runs using --shard 1/4 across multiple runner instances to reduce wall time.
