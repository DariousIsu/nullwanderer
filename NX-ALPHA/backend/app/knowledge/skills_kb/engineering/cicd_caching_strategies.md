CI/CD caching strategies: cache by lockfile hash — requirements.txt or package-lock.json — not by branch, to maximize cache hit rate across all branches. Use fallback keys to restore from a broader match on exact miss. Cache node_modules directly rather than the npm cache directory for faster restore. Docker layer caching: order FROM, RUN, and COPY instructions by change frequency with rarely-changed deps first. Force cache busting weekly by adding a date component to the cache key.
