CodeQL query writing: define a class extending DataFlow::Node for the source, define a class for the sink (e.g., SQL query execution), use DataFlow::Configuration with isSource and isSink predicates, add sanitizers for encoding and validation functions, then run with codeql database analyze. The query language is object-oriented Datalog. Core QL libraries to use: DataFlow, TaintTracking, and SecurityFeatures for common vulnerability patterns.
