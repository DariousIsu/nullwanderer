Memory profiling with memory_profiler: use the @profile decorator on target functions. Run mprof run script.py followed by mprof plot for a time-series view. Line-by-line mode shows per-line allocation costs. For async code use tracemalloc with take_snapshot diffs. Detect object leaks (growing set or dict), large one-time allocations, and fragmentation (use pympler for object size analysis). Fix patterns: generators over lists, weakref for caches to avoid reference cycles.
