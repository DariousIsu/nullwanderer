Async Python profiling: enable asyncio debug mode via PYTHONASYNCIODEBUG=1 to log slow callbacks. Use aiomonitor for live coroutine inspection in a running process. Use yappi for wall-time versus CPU-time breakdown of async code execution. Common issues: blocking calls inside coroutines (use run_in_executor), too many small tasks (batch with asyncio.gather), and lock contention (audit asyncio.Lock usage). Always profile I/O wait time separately from CPU-bound work.
