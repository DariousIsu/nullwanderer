Terraform provider scaffolding: provider block with required_providers and version constraints. Use variables.tf for inputs with validation blocks, outputs.tf for exports, main.tf for resources, and versions.tf to pin provider versions. Module pattern: place modules in a modules/ directory and call with source = "./modules/vpc". Remote state: use an S3 backend with DynamoDB locking for team use — this prevents concurrent apply conflicts and enables state history for rollback.
