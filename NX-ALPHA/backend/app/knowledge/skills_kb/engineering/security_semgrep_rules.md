Semgrep rule authoring: rules.yaml with id, languages, message, severity, and pattern fields. Use pattern-either for OR logic, pattern-not for exclusions, metavariables ($X) for capturing code elements, and focus-metavariable for taint tracking. Run with semgrep --config rules.yaml --output sarif. Publish finished rules to the Semgrep Registry. Test rules using semgrep --test. Use taint mode for full data flow analysis across function boundaries.
