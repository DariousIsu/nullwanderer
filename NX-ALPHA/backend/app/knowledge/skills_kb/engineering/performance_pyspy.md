py-spy CPU profiling: run py-spy record --pid PID --output profile.svg --format speedscope --duration 60 to generate a flamegraph of a live process. Use py-spy top for a real-time CPU view. Use py-spy dump to capture a thread stack snapshot — useful for diagnosing hangs. Works without code modification on any running Python process. Identify hot paths by looking for wide nodes in the flamegraph. GIL activity is displayed separately from CPU time.
