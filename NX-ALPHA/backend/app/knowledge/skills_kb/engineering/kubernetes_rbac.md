Kubernetes RBAC: define Role or ClusterRole with rules specifying apiGroups, resources, and verbs. Bind to ServiceAccounts using RoleBinding or ClusterRoleBinding. Enforce least privilege: give each pod a dedicated ServiceAccount rather than using the default. Audit permissions with kubectl auth can-i --list --as system:serviceaccount:namespace:name. Use OPA or Kyverno for policy enforcement — deny privileged containers and require resource limits on all pods.
