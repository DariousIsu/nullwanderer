Kubernetes secrets management: never store secrets in git. Use External Secrets Operator to sync secrets from Vault or AWS Secrets Manager into Kubernetes Secret objects automatically. Use Sealed Secrets for encrypted secrets committed to git (asymmetric encryption with cluster key). Inject via envFrom/secretRef for env variables or volume mount for file-based secrets like TLS certs. Rotate secrets by updating the source and triggering a rolling restart via an annotation timestamp change.
