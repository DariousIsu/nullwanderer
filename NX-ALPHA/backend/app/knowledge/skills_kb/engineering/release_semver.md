Semantic versioning rules: MAJOR.MINOR.PATCH. Increment MAJOR for breaking API changes, MINOR for backward-compatible new features, PATCH for bug fixes. Pre-release tags: 1.0.0-alpha.1, 1.0.0-rc.1. Build metadata: 1.0.0+build.123 carries no version precedence. Calver (YYYY.MM.DD) is an alternative for date-driven release cadences. In monorepos, use independent versioning per package managed with Changesets to track cross-package dependency bumps automatically.
