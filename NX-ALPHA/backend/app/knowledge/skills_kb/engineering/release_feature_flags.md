Feature flag patterns: boolean flags for gradual rollout from 0% to 5% to 25% to 100%. User-segment flags for controlled beta group access. Kill switches for instant rollback without a deploy. Experiment flags for A/B testing instrumentation. Tools: LaunchDarkly or Flagsmith for enterprise, GrowthBook for open source. Flag lifecycle: create, test, roll out, then clean up — remove from code within 2 sprints of full rollout. Unremoved flags accumulate as significant technical debt over time.
