Wrangler deployment workflow: configure wrangler.toml with name, main entry point, and compatibility_date. Use wrangler dev for local development — connects to remote KV and R2 by default; add --local for fully local execution. Deploy to production with wrangler deploy. Use wrangler deploy --env staging for environment-specific overrides. Store secrets with wrangler secret put KEY — they are encrypted and never appear in wrangler.toml. Configure custom domains via routes. Use wrangler tail for live log streaming from production.
