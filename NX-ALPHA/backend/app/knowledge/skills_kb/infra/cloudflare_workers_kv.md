Cloudflare Workers KV: declare KV binding in wrangler.toml under kv_namespaces with binding name and namespace ID. Read with env.NAMESPACE.get(key) — reads are eventually consistent and globally distributed. Write with env.NAMESPACE.put(key, value, {expirationTtl}) for TTL-based expiry. Enumerate with env.NAMESPACE.list({prefix, limit}). KV is optimized for reads — use Durable Objects when you need strong consistency. Well-suited for config data, session tokens, and feature flag state.
