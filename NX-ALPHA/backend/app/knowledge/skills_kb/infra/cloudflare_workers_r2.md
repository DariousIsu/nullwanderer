Cloudflare R2 object storage: declare r2_buckets binding in wrangler.toml. Write with env.BUCKET.put(key, body, {httpMetadata, customMetadata}). Read with env.BUCKET.get(key) returning an R2Object with body and metadata. Delete with env.BUCKET.delete(key). Zero egress costs compared to S3 make it attractive for high-traffic assets. Expose public URLs directly or generate presigned URLs. Primary use cases: user-generated uploads, static assets, and backup storage. Free tier includes 10GB per month.
