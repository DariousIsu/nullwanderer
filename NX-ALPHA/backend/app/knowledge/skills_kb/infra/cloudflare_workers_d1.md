Cloudflare D1 SQLite: declare d1_databases binding in wrangler.toml. Query with env.DB.prepare(sql).bind(params) followed by .run(), .first(), or .all(). Use env.DB.batch([stmt1, stmt2]) for atomic multi-statement operations. Manage schema migrations with wrangler d1 migrations create and wrangler d1 migrations apply. D1 uses SQLite dialect — not all Postgres features are available. Designed for structured data in Workers without an external database dependency. Current limit is 5GB per database.
