Cloudflare Workers AI: run inference with env.AI.run(model, inputs) where model is a path like @cf/meta/llama-3.1-8b-instruct or @cf/mistral/mistral-7b-instruct-v0.1. Enable streaming with env.AI.run(model, {stream: true}) which returns a ReadableStream. Image classification, translation, and text embeddings are also available. Free tier covers 10k neurons per day. GPU inference runs at the edge with no cold starts, making it well-suited for low-latency AI features in edge-deployed applications.
