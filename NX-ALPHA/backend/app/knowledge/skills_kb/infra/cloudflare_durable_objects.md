Durable Objects for stateful Workers: define a class extending DurableObject with a fetch() handler. Use state.storage for persistent key-value storage. Use state.blockConcurrencyWhile() for atomic operations that must not be interrupted. Single-threaded execution within a single location provides strong consistency guarantees. Primary use cases: multiplayer shared state, per-user rate limiting, WebSocket hibernation, and distributed locks. Bind with [[durable_objects]] in wrangler.toml using a unique namespace per use case.
