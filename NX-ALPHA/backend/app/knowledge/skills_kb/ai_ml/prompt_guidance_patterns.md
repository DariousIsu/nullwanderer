Guidance framework for constrained generation lets you interleave Python logic with LLM output mid-generation. Use gen() for free text, select(options) to constrain to a list, and regex patterns for format enforcement. Stateful context with lm object persists across multiple gen calls in one program. Ideal when you need exact structural control — menus, forms, JSON with computed fields — without post-processing or retry loops. The model never generates invalid tokens due to grammar-level constraints. Install via pip install guidance and load models with guidance.models.LlamaCpp or Transformers backend.
