NeMo benchmark framework supports custom evaluation pipelines integrated with NeMo training workflows. Configure eval tasks in YAML and trigger automatically at checkpoint intervals. Metrics log to W&B or MLflow via built-in callbacks. Use NeMo-Aligner for RLHF-specific eval metrics: reward score distributions, KL divergence from reference policy, win-rate against baseline via preference model. Supports multi-node distributed evaluation for large models. Best suited for enterprise-scale pipelines where you need consistent eval across training runs without managing separate harness infrastructure. Integrates with NeMo Megatron for billion-parameter model evaluation at scale.
