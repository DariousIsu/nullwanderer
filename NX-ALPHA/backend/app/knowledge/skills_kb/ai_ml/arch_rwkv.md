RWKV is an RNN-transformer hybrid that runs in constant memory at inference time — no KV cache growth with sequence length. Uses linear attention approximation via time-mixing (temporal decay of context) and channel-mixing (position-wise FFN). Can be trained efficiently as a transformer in parallel, then executed as a stateful RNN for O(1) per-token inference. Ideal for edge deployment, streaming inference, and long-document processing without memory scaling issues. RWKV-4/5/6 models available on HuggingFace. Use rwkv Python package or via HuggingFace transformers. State can be saved and resumed — useful for persistent conversation memory.
