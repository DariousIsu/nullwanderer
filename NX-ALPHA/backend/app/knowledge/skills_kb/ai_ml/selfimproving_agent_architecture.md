Self-improving agent architecture operates across three nested loops: the inner loop executes tasks using tools and retrieval, logging each step with inputs, outputs, and latency. The outer loop reflects on completed trace quality — scoring coherence, tool selection efficiency, and goal achievement — then writes structured improvement notes. The meta loop periodically batches accumulated traces to update retrieval heuristics (what context types actually helped?) and tool routing weights (which tools succeeded for which query classes?). Store all loop outputs with outcome labels in a persistent memory store. Run periodic batch retraining of the routing classifier on accumulated labeled traces. Gate meta loop updates behind a minimum sample threshold (100+ traces) to prevent overfitting to recent noise.
