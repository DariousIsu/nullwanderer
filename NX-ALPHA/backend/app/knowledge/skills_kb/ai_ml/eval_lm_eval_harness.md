lm-evaluation-harness standardized benchmarking: run with lm_eval --model hf --model_args pretrained=org/model-name --tasks hellaswag,mmlu,truthfulqa,gsm8k --device cuda --batch_size auto --output_path results/. Batch size auto selects maximum that fits in VRAM. Results saved as JSON with per-task accuracy and stderr. Add custom task by creating a YAML file with doc_to_text (input format), doc_to_target (correct answer), and metric (accuracy/exact_match). Use --num_fewshot N to set few-shot count. Compare results against Open LLM Leaderboard baselines. Supports vLLM backend with --model vllm for faster evaluation throughput.
