Pinecone RAG setup: create serverless index with pc.create_index(name, dimension=1536, metric="cosine", spec=ServerlessSpec(cloud="aws", region="us-east-1")). Upsert in batches of 100: index.upsert(vectors=[(id, embedding, metadata_dict)], namespace="tenant_a"). Query with index.query(vector=vec, top_k=5, filter={"category": {"$eq": "docs"}}, include_metadata=True). Use namespaces for multi-tenant isolation — each tenant queries only its namespace. Metadata filter syntax uses MongoDB-style operators ($eq, $in, $gte).
