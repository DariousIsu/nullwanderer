LoRA fine-tuning with PEFT: configure with LoraConfig(r=16, lora_alpha=32, target_modules=["q_proj","v_proj"], lora_dropout=0.05, bias="none", task_type=TaskType.CAUSAL_LM). Apply with model = get_peft_model(base_model, lora_config). r controls rank and capacity — higher r fits more but uses more memory. Train only LoRA params (0.1-1% of total). Save adapter with model.save_pretrained(path). For inference, load base model then apply PeftModel.from_pretrained(base, adapter_path). Merge into base with model.merge_and_unload() to eliminate adapter overhead at inference time.
