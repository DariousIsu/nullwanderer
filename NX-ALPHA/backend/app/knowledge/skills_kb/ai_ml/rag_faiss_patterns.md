FAISS index patterns: IndexFlatL2 is exact brute-force, best for under 100K vectors; IndexIVFFlat requires training, uses nlist centroids (nlist=sqrt(N) as rule of thumb), nprobe controls speed/accuracy tradeoff (nprobe=10-50). Normalize embeddings with faiss.normalize_L2(vectors) before adding for cosine similarity. Save/load with faiss.write_index/read_index. Query pattern: D, I = index.search(query_vec, k=10) returns distances and indices. Batch add with index.add(np.array) for throughput.
