LangChain ReAct agent pattern: define tools as Tool(name="Search", description="useful for looking up current facts", func=search_fn) — description quality is critical for correct routing. Initialize with create_react_agent(llm, tools, prompt) then AgentExecutor(agent, tools, verbose=True, max_iterations=10). The ReAct loop alternates: Thought (reasoning), Action (tool name + input), Observation (tool output), repeating until Final Answer. Set return_intermediate_steps=True to inspect the full reasoning trace for debugging. Add handle_parsing_errors=True for resilience. Use create_openai_functions_agent instead for models with native function calling — more reliable than ReAct string parsing.
