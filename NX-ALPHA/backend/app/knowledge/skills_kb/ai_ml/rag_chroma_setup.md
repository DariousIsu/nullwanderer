Set up ChromaDB for RAG by instantiating a PersistentClient with a persist_directory path. Create a collection with client.get_or_create_collection(name, embedding_function=SentenceTransformerEmbeddingFunction(model_name), metadata={"hnsw:space":"cosine"}). Add documents via collection.add(documents, metadatas, ids). Query with collection.query(query_texts, n_results=5). Filter results by distance threshold (cosine < 0.4 indicates relevance). Use EphemeralClient for in-memory testing only.
