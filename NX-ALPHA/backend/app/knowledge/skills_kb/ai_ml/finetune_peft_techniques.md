PEFT technique comparison: LoRA decomposes weight updates into low-rank matrices (most popular, best for instruction tuning, r=4-64). IA3 scales activations with learned vectors — 10x fewer parameters than LoRA, good for few-shot domain adaptation with minimal data. Prefix Tuning prepends learnable tokens to keys/values — strong for generation tasks, slightly higher memory than LoRA. Prompt Tuning adds soft prompt embeddings only — minimal params, works best at large model scale (11B+). For chat/instruct fine-tuning choose LoRA. For rapid domain shift with few examples choose IA3. All are PEFT-compatible and hot-swappable at inference.
