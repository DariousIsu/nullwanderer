vLLM PagedAttention deployment: instantiate with LLM(model="path/or/hf-id", tensor_parallel_size=N, gpu_memory_utilization=0.9, max_model_len=4096). Create SamplingParams(temperature=0.7, max_tokens=512, top_p=0.95). Run batch inference with outputs = llm.generate(prompts, sampling_params). PagedAttention manages KV cache in non-contiguous pages — enables continuous batching of variable-length requests with near-zero waste. Achieves up to 20x throughput vs HuggingFace generate.
