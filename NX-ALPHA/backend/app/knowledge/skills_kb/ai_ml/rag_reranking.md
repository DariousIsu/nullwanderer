Cross-encoder reranking for RAG: first retrieve 20-50 candidates with fast bi-encoder (cosine similarity), then rerank with cross-encoder/ms-marco-MiniLM-L-6-v2 which scores each query+passage pair jointly. Cross-encoder is far more accurate than cosine alone because it sees both texts simultaneously. Pattern: model.predict([(query, passage) for passage in candidates]), argsort descending, return top 5. Adds 50-100ms latency on GPU, ~500ms on CPU. Use sentence-transformers CrossEncoder class. Also consider bge-reranker-large for highest quality.
