Outlines structured generation converts JSON schemas into finite-state machines that constrain token sampling directly. Use outlines.generate.json(model, MyPydanticSchema) for JSON output, outlines.generate.choice(model, ["A","B","C"]) for classification, outlines.generate.regex(model, pattern) for formatted strings. Works with vLLM (outlines.models.vllm) and transformers backends. Output is always schema-valid — zero post-processing needed. Compile the generator once, reuse across requests. Substantially faster than retry-based approaches. Compatible with any Pydantic v2 model as schema source.
