llama.cpp quantization guide: GGUF is the standard format. Q4_K_M offers the best quality-to-size ratio at ~4.5 bits per weight — use as default. Q5_K_M for quality-priority with ~15% more size. Q8_0 is near-lossless, doubles size of Q4. Q2_K is smallest but significant quality loss. Load in Python with llama-cpp-python: Llama(model_path="model.gguf", n_ctx=4096, n_gpu_layers=-1) for full GPU offload, n_gpu_layers=0 for CPU-only. n_batch=512 for throughput. Call model(prompt, max_tokens=256) or use create_chat_completion for chat format. Supports Metal on Mac, CUDA and ROCm on GPU.
