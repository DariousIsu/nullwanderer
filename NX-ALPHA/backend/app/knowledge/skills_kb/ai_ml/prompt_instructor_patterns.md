Instructor library for structured LLM output: patch the OpenAI client with client = instructor.patch(openai.OpenAI()). Define a Pydantic model for your desired output structure. Call client.chat.completions.create(model=..., response_model=YourModel, messages=[...]). Instructor handles prompt injection and automatic retry on Pydantic validation failure (max_retries=3). Works with Ollama via openai-compatible endpoint: instructor.patch(openai.OpenAI(base_url="http://localhost:11434/v1")). Supports nested models, lists, Optional fields. Use ValidationError hooks for custom retry logic.
