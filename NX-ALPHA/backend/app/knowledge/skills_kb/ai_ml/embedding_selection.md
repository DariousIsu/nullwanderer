Embedding model selection: e5-small-v2 (384d, ~16ms CPU) for latency-critical local use; nomic-embed-text via Ollama (768d) for fully local privacy-preserving pipelines; text-embedding-3-small via OpenAI API (1536d, cheap, strong) for cloud setups; bge-large-en-v1.5 (1024d) for maximum retrieval quality. Always match embedding_dim to your vector DB collection config or queries will fail. Prefix queries with "query: " and passages with "passage: " when using e5 models. Batch encode for throughput, single encode for latency.
