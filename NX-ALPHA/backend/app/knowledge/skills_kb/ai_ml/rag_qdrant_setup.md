Qdrant vector DB setup: create collection with client.recreate_collection(name, vectors_config=VectorParams(size=768, distance=Distance.COSINE)). Upsert with client.upsert(collection_name, points=[PointStruct(id=uuid, vector=embedding, payload={"text": chunk, "source": doc})]). Search with client.search(collection_name, query_vector=vec, limit=5). Filter by payload: query_filter=Filter(must=[FieldCondition(key="source", match=MatchValue(value="doc.pdf"))]). Run locally via qdrant-client in-memory or Docker on port 6333.
