RAG chunking strategies: fixed-size splits at 512 tokens with 50-token overlap work well for uniform document types and predictable retrieval. Use RecursiveCharacterTextSplitter for code (split on class/function boundaries first). Semantic chunking groups sentences by cosine similarity shifts (threshold 0.8) — better for prose but slower. Smaller chunks (256 tokens) improve precision, larger (1024) improve recall of multi-fact answers. Always store metadata: source filename, page number, chunk_index. Avoid splitting mid-sentence; prefer paragraph boundaries.
