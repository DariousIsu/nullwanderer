LlamaIndex RAG pipeline: load docs with SimpleDirectoryReader(dir).load_data(), build index with VectorStoreIndex.from_documents(docs), query with index.as_query_engine(similarity_top_k=5). For agents: wrap query engines as QueryEngineTool(query_engine, metadata=ToolMetadata(name, description)), pass to FunctionCallingAgent.from_tools(tools, llm). Use RouterQueryEngine to route queries across multiple indices by topic. SubQuestionQueryEngine decomposes complex queries into sub-questions answered by different engines, then synthesizes. ObjectIndex for structured data retrieval. Persist index with index.storage_context.persist(persist_dir) and reload with load_index_from_storage.
