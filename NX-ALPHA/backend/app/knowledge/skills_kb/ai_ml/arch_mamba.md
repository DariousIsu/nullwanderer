Mamba state space model scales linearly with sequence length O(L) versus O(L^2) for attention, making it practical for sequences beyond 8K tokens. Uses selective SSM with hardware-aware parallel scan and S4 basis for long-range dependencies. Input-dependent state selection allows the model to filter irrelevant context — equivalent to soft attention without the quadratic cost. Install mamba-ssm package, use MambaLMHeadModel for language tasks. For RAG use cases Mamba handles very long retrieved contexts efficiently. Not yet competitive with Llama-class models on short-context benchmarks but narrows the gap rapidly at 64K+ token lengths.
