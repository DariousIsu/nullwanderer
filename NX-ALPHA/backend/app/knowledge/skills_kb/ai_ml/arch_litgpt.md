LitGPT provides clean, hackable reference implementations of major model families. Download models with litgpt download EleutherAI/model-name. Fine-tune with litgpt finetune --config config.yaml supporting both LoRA and full fine-tuning modes. Run interactive inference with litgpt chat model_dir. Supports Llama 3, Gemma, Phi-3, Mistral, Falcon families. Uses Lightning Fabric for multi-GPU training without boilerplate. Codebase is intentionally minimal — each model in a single file, ideal for understanding internals before modifying architecture. Good for custom architecture experiments, ablations, or embedding into larger systems where you need full control over forward pass.
