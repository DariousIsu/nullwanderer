CrewAI agent role design: create agents with Agent(role="Senior Researcher", goal="find accurate sources", backstory="expert in...", tools=[search_tool], llm=llm, verbose=True). Define tasks with Task(description="research X", agent=researcher, expected_output="bullet list of findings"). Assemble with Crew(agents=[researcher, writer], tasks=[task1, task2], process=Process.sequential) or Process.hierarchical for manager-delegated routing. In hierarchical mode a manager agent auto-routes subtasks to specialists based on role/goal match. Pass context between tasks via task.context=[prior_task]. Use allow_delegation=True on agents that should be able to invoke other agents.
